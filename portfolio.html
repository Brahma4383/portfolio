Hi, I'm Brahmanand — a Software Test Engineer from Navi Mumbai.

I test web applications manually and with automation. I analyse requirements, write test scenarios and test cases, and run functional, regression, smoke and sanity tests. For automation I use Selenium WebDriver, Java and TestNG with the Page Object Model; I test REST APIs in Postman and check backend data with SQL.

At Shubham Tanks And Liners Pvt Ltd my work covers development and testing. I build ERP modules and REST APIs with Python, Django and PostgreSQL, write and run test cases for each module before release, automate regression checks for the key workflows with Selenium, and reproduce, log and retest defects.

Because I build software too, I can trace a bug to its root cause and write reports developers can act on straight away: clear steps, expected and actual results, screenshots, severity and priority. I'm looking for a Manual or Automation Testing role where that mix counts.
